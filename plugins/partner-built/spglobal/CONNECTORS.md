# Connectors — S&P Global

This plugin connects to the **S&P Global Kensho LLM-Ready API** MCP server.

## Overview

The S&P Global MCP server provides structured access to Capital IQ financial data, company intelligence, and earnings transcripts.

## Supercharged Features (with MCPs)

| MCP | Categories | Unlocks | Enhanced Skills |
|-----|------------|---------|-----------------|
| **spglobal** | `market-data`, `financial-data`, `company-intelligence` | S&P Capital IQ live financials, transcripts, and transaction data | `earnings-preview-beta`, `funding-digest`, `tear-sheet` |
