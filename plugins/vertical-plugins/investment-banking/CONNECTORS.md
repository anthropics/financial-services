# Connectors — Investment Banking

This plugin works in **standalone mode** and is **supercharged with MCP connectors**.

## Core Feature Set (Standalone)

- CIM (Confidential Information Memorandum) structuring and drafting
- Anonymous one-page company teaser creation
- Strategic and financial buyer universe mapping
- Accretion/dilution merger modeling
- Investment banking pitch deck and one-page strip profile generation
- M&A process letters, bid instructions, and deal tracking

## Supercharged Features (with MCPs)

| MCP | Categories | Unlocks | Enhanced Skills |
|-----|------------|---------|-----------------|
| **FactSet** | `market-data`, `financial-data` | Live market valuation multiples, consensus estimates, and share pricing | `strip-profile`, `pitch-deck`, `merger-model`, `buyer-list` |
| **S&P Global** | `market-data`, `financial-data`, `company-intelligence` | Capital IQ company profiles, transaction history, and financial metrics | `cim-builder`, `strip-profile`, `teaser`, `datapack-builder` |
| **PitchBook** | `private-markets`, `company-intelligence` | M&A transaction comps, PE/VC sponsor activity, and strategic buyer lists | `buyer-list`, `cim-builder`, `teaser`, `deal-tracker` |
| **Box** | `document-management` | Virtual data room (VDR) file ingestion and secure document delivery | `datapack-builder`, `pitch-deck` |
