# Connectors — Operations & Compliance

This plugin works in **standalone mode** and is **supercharged with MCP connectors**.

## Core Feature Set (Standalone)

- Client and institutional onboarding KYC document parsing
- Ownership, control, and source of funds extraction
- Rule-based KYC risk rating evaluation and policy routing

## Supercharged Features (with MCPs)

| MCP | Categories | Unlocks | Enhanced Skills |
|-----|------------|---------|-----------------|
| **Screening MCP** | `compliance-screening` | Real-time sanctions, PEP (Politically Exposed Persons), and adverse media screening | `kyc-rules`, `kyc-doc-parse` |
