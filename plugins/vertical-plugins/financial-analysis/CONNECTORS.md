# Connectors — Financial Analysis

This plugin works in **standalone mode** (reference docs, templates, and baseline analysis) and is **supercharged with MCP connectors**.

## Core Feature Set (Standalone)

- Comprehensive DCF valuation models and sensitivity tables
- Comparable company analysis (comps) framework and templates
- LBO model shells, debt schedules, and returns calculations
- Three-statement financial model structuring and formula auditing
- Competitive analysis and strategic benchmarking frameworks
- Deck number checking, formatting QC, and Excel/PowerPoint generation
